# Bike Race Champion Portfolio

A responsive portfolio website showcasing the **Bike Race Champion** desktop application, a motorcycle racing championship management system developed using Java, Java Swing, SQL Server, JDBC, and Gemini AI.

## Live Website

[View the live portfolio](https://ghanemsadek2-lang.github.io/Bike-Race-Portfolio/)

## Project Overview

Bike Race Champion is a desktop application designed to manage motorcycle racing championships in an organized and efficient way.

The system includes features for managing riders, teams, countries, seasons, races, registrations, results, standings, and an AI Race Assistant.

## Main Features

- Riders & Teams Management
- Races & Seasons Management
- Registration Management
- Results & Standings
- AI Race Assistant
- Admin and User interfaces

## Technologies Used

- Java
- Java Swing
- Microsoft SQL Server
- JDBC
- Gemini AI
- HTML & CSS
